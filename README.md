# LC Mills Detailing — website

Live at **https://lcmillsdetailing.uk** (GitHub Pages).

- `index.html` — the site (single page)
- `CNAME` — custom domain for GitHub Pages
- `.github/workflows/pages.yml` — deploys to GitHub Pages on every push to `main` and sets the custom domain

To update the site, edit `index.html` and push to `main`.
